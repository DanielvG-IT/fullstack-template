# contracts/

`openapi.json` lands here — **generated by building `services/Acme.Api`, committed, never hand-edited.**

It's the single seam between the two halves of the repo:

```
Acme.Contracts (C# DTOs) ──build──▶ contracts/openapi.json ──codegen──▶ packages/api-client
```

CI regenerates both and fails on `git diff --exit-code`. If that check is red, you changed a DTO
without running `task codegen`.
